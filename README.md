# w10-toolbox

小工具集合。

## color-transition-preview.html — 专辑取色 & 过渡插值预览

参考 Spotify 等音乐 App 的「从封面提取主色作为背景 + 切歌时背景平滑过渡」设计,用来**验证不同颜色插值算法**的小工具。

### 功能

- 从 `img/` 下的图片用 **Median Cut** 提取主色(可选 鲜艳 Vibrant / 主色 Dominant)
- 圆形轮播:滚轮 / 拖拽 / ← → 切换图片
- 切换时背景在多种色彩空间做插值过渡,可实时切换:
  - `sRGB 直插`(基线,发脏)
  - `gamma-linear`(线性光插值,**嵌入式推荐**)
  - `HSL` / `CIELAB` / `OKLab`(最优)
- **分屏对比**两种算法、**纯色 / 渐变**背景切换、可调**时长**与**缓动**
- 每次切换从「当前显示色」重定向出发,插入 / 快速连切都平滑不跳变

### 使用

直接双击 `color-transition-preview.html` 打开即可(图片已 base64 内联进 `img-data.js`,无需起服务器,也绕开 `file://` 下 canvas 读像素被污染的问题)。

滚轮 / 拖拽 / ← → 切换图片,右上角面板调参对比。

## coin_flip/coin-flip.html — 抛硬币动画(3D)& 视频 / 图片导出

俯视白底视角的 **3D** 抛硬币动画:正面 **YES** / 反面 **NO**,点击后硬币向上跳起、边翻转边自转靠近相机(真实透视放大),再落回平面并带小回弹。硬币为**任天堂金币卡通风**(车削圆润厚边 + 扁平明亮卡通金 + 粗圆角描边字 + 干净单内圈,同金色不用字色),配方向光与柔和阴影。可一键**导出视频**或**静态落地 PNG 图片**。

### 功能

- 点击画布 / 按 <kbd>空格</kbd> 抛掷,结果随机(YES / NO 各 50%,自动对齐落地朝上的面)
- 可调**时长**、**翻转圈数**、**靠近程度**(峰值透视放大倍率)、**俯视角**
- **导出视频**(`canvas.captureStream` + `MediaRecorder`,`.webm`),从硬币腾空瞬间开始录制,分辨率 = 面板设置,默认 **360×360**,含常用预设(方形 / 竖屏)
- **导出图片**(`canvas.toBlob`,`.png`),导出当前**静态落地帧**,白底,尺寸 = 同一分辨率设置
- 真 3D:Three.js(r128,UMD)已内置于 `coin_flip/lib/`,无需联网

### 使用

直接双击 `coin_flip/coin-flip.html` 打开即可,无需服务器(离线可用)。导出录制建议用 Chrome / Edge。
