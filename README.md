# w10-toolbox

小工具集合。

## color-transition-preview.html — 专辑取色 & 过渡插值预览

参考 Spotify 等音乐 App 的「从封面提取主色作为背景 + 切歌时背景平滑过渡」设计,用来**验证不同颜色插值算法**的小工具。

### 功能

- 从 `img/` 下的图片用 **Median Cut** 提取主色(可选 鲜艳 Vibrant / 主色 Dominant)
- 圆形轮播:滚轮 / 拖拽 / ← → 切换图片
- 切换时背景在多种色彩空间做插值过渡,可实时切换:
  - `sRGB 直插`(基线,发脏)
  - `gamma-linear`(线性光插值,**嵌入式推荐**)
  - `HSL` / `CIELAB` / `OKLab`(最优)
- **分屏对比**两种算法、**纯色 / 渐变**背景切换、可调**时长**与**缓动**
- 每次切换从「当前显示色」重定向出发,插入 / 快速连切都平滑不跳变

### 使用

直接双击 `color-transition-preview.html` 打开即可(图片已 base64 内联进 `img-data.js`,无需起服务器,也绕开 `file://` 下 canvas 读像素被污染的问题)。

滚轮 / 拖拽 / ← → 切换图片,右上角面板调参对比。
