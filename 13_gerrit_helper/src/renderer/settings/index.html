Gerrit Helper

服务器与认证

HTTP REST 认证（仅 REST 通道用得上）

密码在 Gerrit 的 Settings → HTTP Credentials 生成，不是登录密码；本机用系统 DPAPI 加密保存。 ~/.gitcookies 模式不复制 cookie，每次请求现读那个文件。

跟踪项

reviewer:self is:open 待我评审 · owner:self status:open 我提交的 · project:xxx status:open 整个项目

显示

这里的改动会立刻应用到悬浮层，方便对着看效果；点「保存」才写进配置，直接关窗则复原。

预览：等待操作

真亚克力需要 Windows 11（build 22000+）；不可用时自动回落到半透明底色。

Jenkins 构建监控

Token 在 Jenkins 右上角 你的用户名 → Configure → API Token 生成。 和 Gerrit 密码一样用系统 DPAPI 加密保存。

控制台日志下载目录

留空 = 程序目录下的 build_log（第一次下载时自动创建）。 文件名是 job名-构建号-console.txt，同一轮重复下载会覆盖。

通知

同一事件跨轮不重复弹；一次刷新超过 3 条会合并成一条。

高级

导出的文件不含凭据（密码 / Token），换机器导入后需要重填一次。
